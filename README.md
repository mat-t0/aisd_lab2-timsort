# aisd_lab2-timsort  
##Сортировки. 
Реализовать сортировку Timsort (https://ru.wikipedia.org/wiki/Timsort).  

## [В реализации должны быть выполнены все основные элементы алгоритма:]() 
 - сортировка вставками,
 - поиск последовательностей run,
 - подсчёт minrun,
 - слияние последовательностей run,
 - режим галопа при слиянии.
